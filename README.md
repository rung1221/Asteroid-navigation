2025“定位与导航”课程设计报告要求
1、题目
2200年，人类已真正迎来了太空探索的新纪元，深空探测、太空采矿、地外天体上的有人长期驻扎已不再是科学幻想。为了进一步节约地球资源、建设好美丽地球家园，联合国在中国的大力倡导下，开启了在太阳系小行星带的太空采矿计划。
开展小行星带的太空采矿，需要一款兼具灵活自主、稳定可靠的机器人系统，以实现在不同小行星间的灵活穿梭与物资运输。跳蚤（甲-3型）机器人是一款由我国自主研发的具备自主采矿、跳跃运动、物资运输功能于一体的机器人系统。
该机器人系统采用核动力装置驱动，可安装配备各类常规仪器设备，保证其正常工作与运行。
小行星间跳跃穿梭存在的主要难点：
1）小行星的高速运动；
2）空间恶劣环境的干扰；
3）外部导航信息无法连续获取；
4）安全保密因素等。
2、报告要求
请围绕“跳蚤（甲-3型）”机器人的小行星间“跳跃”任务，提出一种导航系统的设计方法，需要完成以下内容：
1）请进行导航系统的初步功能设计、主要指标设计与简要论证等；
2）请对你所提出导航系统的原理进行介绍，需要提供详尽的原理方法；
3）请进行导航任务实施的流程设计。

1.1 研究背景
随着深空探测任务的不断推进，小行星作为重要的天体资源载体和行星科学研究对象，越来越受到世界各国航天机构的广泛关注。小行星探测任务不仅有助于了解太阳系的起源和演化，还对未来资源获取、地球防御和载人深空探索具有重要战略意义。近年来，日本“隼鸟”系列任务、NASA的“欧西里斯-雷克斯”任务等成功实现了对小行星的接近、采样及返回操作，标志着人类在深空环境下的自主探测与作业能力取得了重大突破。
当前大多数任务依然集中在单颗小行星的近距离探测与样本采集，任务周期长、成本高、覆盖范围有限，难以满足对多个小行星同时或连续探测的科学需求。为提升探测效率、拓展任务边界，国内外开始关注具有自主跳跃能力的微型机器人，在多个小行星表面或轨道间进行穿梭式作业。“跳蚤（甲-3型）”机器人便是针对该需求而提出的一种小型化、低功耗、具有自主跳跃与导航功能的空间机器人平台。
小行星间的跳跃穿梭任务面临极高的技术挑战，尤其是在微重力环境中，跳跃过程将导致机器人与目标天体之间的相对运动呈强非线性演化。同时，深空环境中的强辐射、温差、尘埃扰动以及导航信息不连续，均会对系统的自主导航能力提出极高要求。因此，设计一套适用于“跳蚤（甲-3型）”机器人的高精度、高鲁棒性导航系统，是实现跨小行星跳跃探测任务的关键技术前提。
1.2 研究意义
“跳蚤（甲-3型）”机器人通过跳跃方式在多个小行星间实现探测任务，有望大幅提升深空探测器的空间覆盖能力与资源利用效率。相较于传统轨道飞行器，其结构更紧凑，跳跃控制更灵活，适合在复杂地形和低重力环境下执行自主作业。为了支持其跨小行星任务能力，导航系统必须具备以下能力：
1）在无连续外部导航信号（如GPS）的深空环境中，依靠自主观测手段获取自身状态信息；

2）实时处理跳跃过程中的高速相对运动带来的非线性导航误差；
3）具备高容错性与鲁棒性，能够在外部环境扰动（如太阳风、尘埃干扰等）下保持导航精度；
4）可与轨迹规划、跳跃控制等模块高效协同，实现多跳跃任务的连续执行。
因此，设计适配“跳蚤（甲-3型）”任务特点的导航系统，对于推进小行星多目标快速探测、提升任务效率与智能化水平具有重大意义，也为未来资源采集型空间机器人系统提供了关键技术支撑。
1.3 研究现状
主要是有两个大方向进行研究：导航和路径规划和着陆取样。
（1）导航和路径规划现状分析
在小行星探测任务中，由于其环境具有微重力、强不确定性和地形复杂等特点，任务实施过程中涉及的导航、控制与协同调度等问题尤为关键。为应对外部导航信息缺失的挑战，自主导航技术成为研究重点。杨慧欣将近地小行星近距离卫星编队的自主导航问题建模为多传感器组合的信息融合与构形控制问题。文中提出了融合小行星观测数据与星间相对观测信息的自主导航方法，并设计了基于循环追踪算法的编队控制策略。通过引入星间观测信息，该方法显著提升了导航精度，将位置估计误差降低至米级，速度估计误差提升至 10⁻⁵ 米/秒量级，同时增强了系统的鲁棒性和可靠性。大量仿真结果表明，该方法在导航精度和任务适应性方面均优于传统方法，尤其在传感器失效或观测信息丢失情况下依然保持高精度。
针对轨道转移与采样返回任务，刘靖怡将近地小行星取样返回任务的轨道转移优化问题，建模为多目标轨道优化与天体借力转移设计问题。作者提出了基于NSGA-II的多目标优化模型，综合考虑剩余质量、转移时间和速度增量等指标，系统研究了两脉冲、三脉冲日心转移轨道以及月球借力等多种轨道设计策略。仿真结果表明，所提出的优化设计方法能够显著拓展小行星目标遴选范围，降低轨道转移的速度增量，提高任务灵活性，为我国小行星采样返回任务提供了理论和方法支持。在此基础上董博文关注了高倾角轨道转移的特殊需求，将近地小行星飞越探测的轨道设计问题，转化为基于大幅值逆行轨道（DRO）空间站的多阶段转移优化问题。作者提出了DRO调相轨道机制，使探测器能够从任意相位出发或返回，极大地降低了对轨道站相位的依赖。通过引入地球与月球联合借力设计，实现了几十度高倾角变化下仅需百米每秒级速度增量，解决了传统设计中高倾角转移的高能耗问题。实际星历下的仿真验证了该方法的可行性和复杂天体运动环境下的鲁棒性，为未来小行星资源开发和威胁防范任务提供了新思路。
随着任务环境复杂度的进一步提升，路径规划中的不确定性问题也日益受到关注。Liu等人将充满不确定性条件下的小行星路径约束轨迹优化问题，转化为机会约束下的凸优化问题。研究人员提出了一种新型的无损凸化方法，通过引入额外变量和虚拟缓冲区，将非凸约束转化为可高效求解的机会约束，确保了轨迹优化的收敛性和安全性。作者建立了适用于状态、动力学均不确定情况下的随机最优轨迹优化框架，利用蒙特卡洛仿真验证了方法在着陆与跳跃任务中的稳健性和高效碰撞规避能力，填补了小行星接近轨迹随机最优控制领域的空白。Wang等人进一步将近地小行星飞越探测的轨迹优化问题建模为地月引力助推与相位策略相结合的分阶段优化模型。研究针对可重复使用探测器提出了低能量转移轨道设计，有效降低了平面变化所需速度增量。与传统直接往返方法相比，该方法在速度增量上实现了超过50%的减少，并通过全局与局部优化算法结合，提升了算法收敛速度和探测效率。实际任务中，10年内成功实现了47颗小行星的探测，显著提升了探测器的复用率和任务灵活性，验证了地月空间作为深空探测中转平台的巨大潜力。
（2）着陆取样控制现状分析
在小行星表面运动与着陆控制方面，传统控制策略难以应对微重力下的动态跳跃与非连续接触过程，因此需要更复杂的控制建模与实时调度策略。Tsuda等人系统总结了“隼鸟2号”任务在小行星龙宫上的着陆、漫游、撞击坑形成等全过程，将复杂的多目标操作问题转化为工程与科学活动的集成优化问题。通过同步推进科学观测与工程控制，团队成功实现了多项世界首创，包括两次着陆采样、漫游器和着陆器的多点部署，以及动力撞击器制造人工撞击坑等。文章详细描述了面对龙宫复杂地形和极端环境时采取的多项应对措施，验证了多探测器协同操作和自主着陆采样等关键技术的可行性，为后续深空探测任务提供了经验和新视角。
顺应任务需求的复杂化，李泰博将小行星资源勘探与利用任务建模为多目标轨迹优化与智能控制问题。提出了时间最优-燃耗最优同伦法、受限功率指数同伦法和双比冲对数同伦法，系统解决了推力转移轨道的优化难题。对于着陆前悬停与着陆控制，文中设计了基于滑模控制的奖励函数和双策略强化学习算法，有效提升了网络收敛效率和控制性能。分层强化学习option-PPO算法在避障着陆控制中表现优异，显著提升了自主控制的鲁棒性和精度。大量仿真结果显示，所提方法在工程实际中具有较高的适用性和可靠性。张莹莹针对小行星自主着陆中的动力学耦合、多约束和不确定性问题，将着陆轨迹优化问题转化为凸优化问题，提出了结合序列凸规划与模型预测控制的混合方法。该方法通过引入虚拟控制和信赖域约束，提升了解的可行性和收敛性。与传统hp-伪谱法相比，所提方法在精度、计算效率和实时性方面表现优越，特别适合实时自主着陆场景。模型预测控制的应用进一步增强了系统的抗扰动能力和鲁棒性，在复杂环境下实现了高精度着陆，显著提升了小行星探测任务的成功率。
在轨迹规划和控制理论不断完善的同时，研究者也在探索适应小行星特殊环境的创新着陆策略。Liang等人将小行星精确着陆建模为主动跳跃轨迹规划问题，提出了一种利用姿态序列控制和分段跳跃运动的新型导引方法。该策略通过动态规划跳跃轨迹，显著减少了参数扰动对着陆误差的影响，并能适应斜面等复杂地形。仿真结果显示，主动跳跃轨迹方法在鲁棒性、误差抑制及适应性方面均优于传统方法，为小行星表面高精度着陆任务提供了创新性的技术路径。Qi等人关注于小行星上四足机器人着陆与姿态一体化控制问题，将其转化为多目标强化学习优化问题。作者提出基于自动调节奖励函数权重的无模型强化学习控制器，解决了多目标稀疏奖励导致的训练效率低下难题。多轮仿真实验表明，该方法能在重力分布不均且包含水平分量的极端环境下，实现高成功率的软着陆和稳定姿态控制，显著优于传统控制器，展示了智能机器人在空间探索中的潜力。
